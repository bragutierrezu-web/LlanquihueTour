📘 Descripción general del sistema
Mi proyecto desarrollado en Java busca gestionar correctamente una agencia de turismo sobre Tours en Llanquihue. El programa permite registrar a los clientes con todos sus datos personales(Usando herencia desde la clase persona) como sus nombres, rut, teléfonos y más información necesaria, además creando diferentes opciones de tours
con sus respectivos destinos, precios y duraciones, mostrando así los resultados de todo lo pedido en la consola de IntelliJ





🧱 Estructura general del proyecto
📁 src/       
├── Model/        # Carpeta con las clases de Dominio (Persona, Cliente y Tour)
├── org.examples/       # Paquete principal con la clase Main



⚙️ Instrucciones para clonar y ejecutar el proyecto

Abre el proyecto en IntelliJ IDEA.

Dirígete a la carpeta Scr y ejecuta el archivo Main.java desde el paquete org.example
